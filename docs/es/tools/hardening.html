Reforzar tu privacidad

Reforzar la privacidad es cerrar las brechas de las herramientas que ya usas: navegador, contraseñas, mensajes y archivos.

Empieza por lo que usas a diario. Cada ficha indica si su código es abierto y qué te pide.

Orden: lo que la herramienta te pide (nada, una cuenta, un documento de identidad), después código abierto antes que cerrado, después orden alfabético. Los enlaces de afiliado y los patrocinadores no lo cambian.

Navegadores

  1. LibreWolf

    Te pide: nada Código: código abierto
    • Versión personalizada de Firefox centrada en la privacidad, la seguridad y la libertad.
    • Busca eliminar la telemetría y la recogida de datos. Incluye uBlock Origin.
    • Windows, Linux, macOS y OpenBSD.

    Visitar LibreWolf Comprobado el 2026-10-19

  2. Mullvad Browser

    Te pide: nada Código: código abierto
    • Creado con el Tor Project para reducir el rastreo y las huellas.
    • Busca dar a todos los usuarios huellas parecidas y usa letterboxing.
    • Linux, macOS y Windows. Gratis, uses o no Mullvad VPN.

    Visitar Mullvad Browser Última versión: 2026-10-14 Comprobado el 2026-10-19

  3. Firefox

    Te pide: nada Código: no indicado
    • Creado por Mozilla, que dice no pertenecer a accionistas.
    • Bloquea rastreadores automáticamente. Dice que nunca venderá tus datos personales.
    • Windows, macOS, Linux, iOS y Android.
    • Su página no hace ninguna declaración sobre el código abierto.

    Visitar Firefox Comprobado el 2026-10-19

Extensiones

  1. uBlock Origin

    Te pide: nada Código: código abierto
    • Bloqueador de contenido para Chromium y Firefox, pensado para gastar poca CPU y memoria.
    • Funciona mejor en Firefox, en ordenador y Android. Su ficha en la Chrome Web Store fue retirada.
    • Licencia GPLv3.

    Visitar uBlock Origin Última versión: 2026-09-16 Comprobado el 2026-10-19

Motores de búsqueda

  1. SearXNG

    Te pide: nada Código: código abierto
    • Metabuscador gratuito que reúne resultados de hasta 264 servicios de búsqueda.
    • Dice que los usuarios no son rastreados ni perfilados. Puedes alojar tu propia instancia o usarlo por Tor.
    • Licencia AGPL-3.0.

    Visitar SearXNG Comprobado el 2026-10-19

  2. DuckDuckGo

    Te pide: nada Código: no indicado
    • Dice: «DuckDuckGo nunca te rastrea».
    • Dice que sus anuncios se muestran en colaboración con Microsoft y que verlos es anónimo.
    • La página que leímos no dice de dónde vienen sus resultados.

    Visitar DuckDuckGo Comprobado el 2026-10-19

  3. Mojeek

    Te pide: nada Código: no indicado
    • Buscador con su propio índice de más de nueve mil millones de páginas.
    • Dice ofrecer búsqueda independiente sin rastreo desde hace más de 15 años.

    Visitar Mojeek Comprobado el 2026-10-19

Gestores de contraseñas

  1. KeePassDX

    Te pide: nada Código: código abierto
    • Gestor de contraseñas para Android que abre bases de datos de KeePass.
    • Licencia GPL-3.0.

    Visitar KeePassDX Última versión: 2026-10-17 Comprobado el 2026-10-19

  2. KeePassXC

    Te pide: nada Código: código abierto
    • Gestor de contraseñas de código abierto que guarda tus contraseñas en un archivo cifrado sin conexión.
    • Dice que no se guarda ningún dato en servidores remotos.
    • Windows, macOS y Linux. Licencia GPLv3.

    Visitar KeePassXC Última versión: 2026-03-10 Comprobado el 2026-10-19

  3. Bitwarden

    Te pide: una cuenta Código: código abierto
    • Gestor de contraseñas de código abierto y cifrado de extremo a extremo.
    • Siempre gratis para la gestión básica de contraseñas.
    • Dice que publica los resultados de sus auditorías de seguridad hechas por terceros.
    • Los planes para empresas pueden autoalojarse.

    Visitar Bitwarden Última versión: 2026-10-15 Comprobado el 2026-10-19

  4. Proton Pass

    Te pide: una cuenta Código: código abierto
    • Gestor de contraseñas cifrado de extremo a extremo con plan gratuito: inicios de sesión, notas y tarjetas ilimitados.
    • El plan gratuito incluye 10 alias hide-my-email.
    • Su tabla comparativa presenta Proton Pass como de código abierto.

    Visitar Proton Pass Comprobado el 2026-10-19

Mensajería

  1. SimpleX Chat

    Te pide: nada Código: código abierto
    • Mensajería sin identificadores de usuario, ni siquiera aleatorios.
    • Dice que ninguna entidad controla la red y que cualquiera puede ejecutar servidores.
    • Escritorio, iOS y Android.

    Visitar SimpleX Chat Última versión: 2026-09-26 Comprobado el 2026-10-19

  2. Briar

    Te pide: no indicado Código: código abierto
    • Mensajería entre pares que evita los servidores centrales, por Bluetooth, Wi-Fi o Tor.
    • Libre y de código abierto. Se distribuye en Google Play y F-Droid.

    Visitar Briar Comprobado el 2026-10-19

  3. Molly

    Te pide: no indicado Código: código abierto
    • Fork independiente de Signal para Android, con base de datos cifrada con contraseña y compatibilidad con Tor mediante Orbot.
    • Dice que es software totalmente libre, sin blobs propietarios.

    Visitar Molly Última versión: 2026-07-31 Comprobado el 2026-10-19

  4. Signal

    Te pide: no indicado Código: código abierto
    • Mensajería gestionada por una organización independiente sin ánimo de lucro, con cifrado de extremo a extremo.
    • Basada en el protocolo Signal, de código abierto.
    • Su página no dice si se exige un número de teléfono.

    Visitar Signal Última versión: 2026-10-13 Comprobado el 2026-10-19

Cifrado

  1. Cryptomator

    Te pide: nada Código: código abierto
    • Cifrado en el cliente para los archivos que guardas en cualquier nube.
    • Código abierto. La descarga para escritorio es gratuita.

    Visitar Cryptomator Última versión: 2026-06-29 Comprobado el 2026-10-19

  2. GnuPG

    Te pide: nada Código: código abierto
    • Implementación libre del estándar OpenPGP, que se usa desde la línea de comandos.
    • Software libre desde 1997, bajo la licencia GNU GPL.
    • Hay una versión para Windows a través de Gpg4win.

    Visitar GnuPG Comprobado el 2026-10-19

  3. VeraCrypt

    Te pide: nada Código: código abierto
    • Software libre y de código abierto de cifrado de discos para Windows, macOS y Linux, basado en TrueCrypt 7.1a.
    • Las notas de su versión 1.19 mencionan correcciones de una auditoría de Quarkslab financiada por la OSTIF.

    Visitar VeraCrypt Última versión: 2026-06-12 Comprobado el 2026-10-19

    • Borrado seguro de archivos. Windows y Linux.

    Visitar BleachBit Última versión: 2026-09-08 Comprobado el 2026-10-19

    • Lee, escribe y edita metadatos en una gran variedad de archivos.

    Te pide: nada Código: no indicado
