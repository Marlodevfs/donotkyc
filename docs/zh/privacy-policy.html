隐私政策

DoNotKYC 不出售数据，也不保存任何关于你的个人数据。

本站不使用的东西

  • 没有广告追踪器，没有 Cookie。
  • 字体、图片和代码都来自 www.donotkyc.com。唯一的外部脚本是下面说明的访问计数器。
  • 你在本站输入的任何内容都不会发送给我们。提交和更正通过 GitHub 进行，适用 GitHub 自己的隐私声明。

留在你设备上的内容

如果你切换浅色和深色主题，浏览器会在本地存储中记住这个选择。站内搜索也在你的浏览器中运行：你的搜索词不会发往任何地方。

访问计数器

我们用 GoatCounter 统计访问量，这是一个不使用 Cookie 的开源计数器。它记录被打开的页面、来源网站、浏览器、国家和屏幕尺寸，不记录你的姓名，也不会跨站跟踪你。我们只是想知道有多少人在读这个网站。

托管

本站托管在 GitHub Pages 上。出于安全原因，GitHub 会记录访客的 IP 地址。我们无法访问这些日志。GitHub 的说明（英文）。

指向其他网站的链接

当你点击平台链接时，你就离开了 DoNotKYC，适用该网站的政策。推广链接会告诉平台你来自我们；它不会告诉我们任何关于你的信息。见我们如何赚钱。
