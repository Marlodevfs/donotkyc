隐私加固

隐私加固就是补上你已在使用的工具中的漏洞：浏览器、密码、消息和文件。

先从每天使用的开始。每个条目说明代码是否开源，以及它向你要求什么。

排序：工具向你要什么（什么都不要、账户、证件），然后开源在闭源之前，最后按字母顺序。推广链接和赞助商不会改变排序。

浏览器

  1. LibreWolf

    要求: 无 代码: 开源
    • 注重隐私、安全和自由的 Firefox 定制版。
    • 目标是移除遥测和数据收集。内置 uBlock Origin。
    • Windows、Linux、macOS 和 OpenBSD。

    访问 LibreWolf 检查日期 2026-10-19

  2. Mullvad Browser

    要求: 无 代码: 开源
    • 与 Tor Project 合作开发，用于减少追踪和指纹。
    • 目标是让所有用户拥有相似的指纹，并使用 letterboxing。
    • Linux、macOS 和 Windows。无论你是否使用 Mullvad VPN 都免费。

    访问 Mullvad Browser 最新版本： 2026-10-14 检查日期 2026-10-19

  3. Firefox

    要求: 无 代码: 未说明
    • 由 Mozilla 开发，后者称自己不属于任何股东。
    • 自动拦截追踪器。称永远不会出售你的个人数据。
    • Windows、macOS、Linux、iOS 和 Android。
    • 其页面没有任何关于开源的声明。

    访问 Firefox 检查日期 2026-10-19

扩展

  1. uBlock Origin

    要求: 无 代码: 开源
    • 适用于 Chromium 和 Firefox 的内容拦截器，占用 CPU 和内存都很少。
    • 在 Firefox 上效果最好，桌面和 Android 均可。其 Chrome 应用商店页面已被移除。
    • GPLv3 许可证。

    访问 uBlock Origin 最新版本： 2026-09-16 检查日期 2026-10-19

搜索引擎

  1. SearXNG

    要求: 无 代码: 开源
    • 免费的元搜索引擎，聚合多达 264 个搜索服务的结果。
    • 称用户既不被追踪也不被画像。你可以自己搭建实例，或通过 Tor 使用。
    • AGPL-3.0 许可证。

    访问 SearXNG 检查日期 2026-10-19

  2. DuckDuckGo

    要求: 无 代码: 未说明
    • 称：“DuckDuckGo 从不追踪你。”
    • 称其广告与微软合作投放，且观看广告是匿名的。
    • 我们读到的页面没有说明其搜索结果来自哪里。

    访问 DuckDuckGo 检查日期 2026-10-19

  3. Mojeek

    要求: 无 代码: 未说明
    • 拥有自己索引的搜索引擎，收录超过 90 亿个页面。
    • 称 15 年多来一直提供不追踪的独立搜索。

    访问 Mojeek 检查日期 2026-10-19

密码管理器

  1. KeePassDX

    要求: 无 代码: 开源
    • 可打开 KeePass 数据库的 Android 密码管理器。
    • GPL-3.0 许可证。

    访问 KeePassDX 最新版本： 2026-10-17 检查日期 2026-10-19

  2. KeePassXC

    要求: 无 代码: 开源
    • 开源密码管理器，把密码保存在离线加密文件中。
    • 称不会在远程服务器上存储任何数据。
    • Windows、macOS 和 Linux。GPLv3 许可证。

    访问 KeePassXC 最新版本： 2026-03-10 检查日期 2026-10-19

  3. Bitwarden

    要求: 账户 代码: 开源
    • 开源、端到端加密的密码管理器。
    • 基础密码管理功能始终免费。
    • 称会公布第三方安全审计的结果。
    • 企业套餐可以自托管。

    访问 Bitwarden 最新版本： 2026-10-15 检查日期 2026-10-19

  4. Proton Pass

    要求: 账户 代码: 开源
    • 端到端加密的密码管理器，免费套餐不限登录、笔记和银行卡数量。
    • 免费套餐包含 10 个 hide-my-email 别名。
    • 其对比表把 Proton Pass 列为开源。

    访问 Proton Pass 检查日期 2026-10-19

    要求: 无 代码: 开源
    • 适用于 Android 的免费开源验证器应用。

    访问 Aegis Authenticator 最新版本： 2026-09-06 检查日期 2026-10-19

  2. Nitrokey

    要求: 无 代码: 开源
    • 销售开源安全硬件（包括安全密钥）的德国公司。
    • 称其产品在德国制造。

    访问 Nitrokey 最新版本： 2026-09-30 检查日期 2026-10-19

  3. YubiKey

    要求: 无 代码: 未说明
    • 支持 FIDO2、U2F、智能卡、OTP 和 OpenPGP 的安全密钥系列。
    • 其页面没有说明产地，也没有关于开源的声明。

    访问 YubiKey 检查日期 2026-10-19

  4. Ente Auth

    要求: 未说明 代码: 开源
    • 开源 2FA 验证器，带端到端加密的云备份。
    • 提供手机、桌面和网页应用。免费。

    访问 Ente Auth 检查日期 2026-10-19

即时通讯

  1. SimpleX Chat

    要求: 无 代码: 开源
    • 没有用户标识符的即时通讯，连随机标识符也没有。
    • 称没有任何实体控制网络，任何人都可以运行服务器。
    • 桌面、iOS 和 Android。

    访问 SimpleX Chat 最新版本： 2026-09-26 检查日期 2026-10-19

  2. Briar

    要求: 未说明 代码: 开源
    • 绕开中心服务器的点对点消息，通过蓝牙、Wi-Fi 或 Tor 传输。
    • 自由开源。通过 Google Play 和 F-Droid 分发。
    • 其页面没有说明是否要求账户。

    访问 Briar 检查日期 2026-10-19

  3. Molly

    要求: 未说明 代码: 开源
    • Signal 的独立 Android 分支，带口令加密的数据库，并通过 Orbot 支持 Tor。
    • 称它是完全的自由软件，没有专有二进制块。

    访问 Molly 最新版本： 2026-07-31 检查日期 2026-10-19

  4. Signal

    要求: 未说明 代码: 开源
    • 由独立非营利组织运营、带端到端加密的即时通讯。
    • 基于开源的 Signal 协议。
    • 其页面没有说明是否要求手机号。

    访问 Signal 最新版本： 2026-10-13 检查日期 2026-10-19

加密

  1. Cryptomator

    要求: 无 代码: 开源
    • 对你存放在任何云盘里的文件做客户端加密。
    • 开源。桌面版免费下载。

    访问 Cryptomator 最新版本： 2026-06-29 检查日期 2026-10-19

  2. GnuPG

    要求: 无 代码: 开源
    • OpenPGP 标准的自由实现，通过命令行使用。
    • 自 1997 年起就是自由软件，采用 GNU GPL。
    • 可通过 Gpg4win 获得 Windows 版本。

    访问 GnuPG 检查日期 2026-10-19

  3. VeraCrypt

    要求: 无 代码: 开源
    • 适用于 Windows、macOS 和 Linux 的免费开源磁盘加密软件，基于 TrueCrypt 7.1a。
    • 其 1.19 版本说明提到修复了 OSTIF 资助的 Quarkslab 审计所发现的问题。

    访问 VeraCrypt 最新版本： 2026-06-12 检查日期 2026-10-19

元数据清理工具

  1. BleachBit

    要求: 无 代码: 开源
    • 开源清理工具，可清理临时文件、浏览器缓存、日志和痕迹。
    • 安全删除文件。Windows 和 Linux。
    • GPLv3 许可证。

    访问 BleachBit 最新版本： 2026-09-08 检查日期 2026-10-19

  2. ExifTool

    要求: 无 代码: 未说明
    • 读取、写入和编辑多种文件中的元数据。
    • 可逐项、按组或整体删除元数据。其页面称不保证完全清除。

    访问 ExifTool 检查日期 2026-10-19

  3. MAT2

    要求: 无 代码: 未说明
    • 适用于许多常见文件格式的元数据清除工具，用 Python 3 编写。
    • 一个带命令行界面和文件管理器扩展的库。

    访问 MAT2 检查日期 2026-10-19

文件共享

  1. OnionShare

    要求: 无 代码: 开源
    • 通过 Tor 分享文件的开源工具。也可以托管洋葱网站或聊天室。
    • Windows、macOS、Linux、Android 和 iOS。GPLv3 许可证。

    访问 OnionShare 最新版本： 2026-10-16 检查日期 2026-10-19

  2. Syncthing

    要求: 无 代码: 开源
    • 在你自己的电脑之间持续同步文件，没有中心服务器。
    • Windows、macOS、Linux、FreeBSD 等。据其仓库，采用 MPL-2.0 许可证。

    访问 Syncthing 最新版本： 2026-10-06 检查日期 2026-10-19
