电脑操作系统

你的操作系统能看到你做的一切。这些系统从普通的 Linux 发行版到专为不留痕迹而设计的系统都有。

其中几个可以从 U 盘或在虚拟机里启动，所以你不用清空电脑就能试用。

排序：工具向你要什么（什么都不要、账户、证件），然后开源在闭源之前，最后按字母顺序。推广链接和赞助商不会改变排序。

条目为英文。

  1. Arch Linux

    要求: 无 代码: 开源
    • Independently developed x86-64 GNU/Linux distribution with a rolling release.
    • Minimal base system: you add only the software you need.

    访问 Arch Linux 检查日期 2026-10-19

  2. Debian

    要求: 无 代码: 开源
    • Calls itself a complete Free Operating System, built by a community of people.

    访问 Debian 检查日期 2026-10-19

  3. Fedora Workstation

    要求: 无 代码: 开源
    • GNOME desktop built on open source technology.
    • Says it is free, has no ads and that your data belongs to you.

    访问 Fedora Workstation 检查日期 2026-10-19

  4. FreeBSD

    要求: 无 代码: 开源
    • Operating system known for network performance and stability.
    • BSD-style license that allows redistribution and modification.

    访问 FreeBSD 检查日期 2026-10-19

  5. Kicksecure

    要求: 无 代码: 开源
    • Secure by default system based on Debian.
    • Runs on a physical computer, from a USB stick or in a virtual machine.
    • Says all its source code uses OSI approved licenses.

    访问 Kicksecure 检查日期 2026-10-19

  6. NixOS

    要求: 无 代码: 开源
    • Linux system configured declaratively with Nix.
    • Says a package that works on one machine works on another.
    • Nix is LGPL 2.1 and Nixpkgs is MIT.

    访问 NixOS 检查日期 2026-10-19

  7. OpenBSD

    要求: 无 代码: 开源
    • Free, multi-platform Unix-like operating system based on 4.4BSD.
    • Says: "Only two remote holes in the default install, in a heck of a long time!"
    • Developed by volunteers and funded by donations.

    访问 OpenBSD 检查日期 2026-10-19

  8. openSUSE Tumbleweed

    要求: 无 代码: 开源
    • Continuously updated: you install it once.
    • Its page links to the source code and to a license page.

    访问 openSUSE Tumbleweed 检查日期 2026-10-19

  9. Qubes OS

    要求: 无 代码: 开源
    • Free and open source system built on compartmentalization.
    • Brings the security of the Xen hypervisor to personal computers.
    • Its home page links to a separate page for hardware requirements.

    访问 Qubes OS 检查日期 2026-10-19

  10. secureblue

    要求: 无 代码: 开源
    • Security-focused desktop and server Linux system built on Fedora Atomic Desktop images.
    • Developed as an open source project. Apache 2 license.

    访问 secureblue 检查日期 2026-10-19

  11. Tails

    要求: 无 代码: 开源
    • Starts from a USB stick instead of Windows, macOS or Linux.
    • Uses the Tor network for everything you do online.
    • Says it leaves no trace on the computer when you shut it down.
    • Free software that independent researchers can verify.

    访问 Tails 检查日期 2026-10-19

  12. Whonix

    要求: 无 代码: 开源
    • Routes all internet traffic through Tor with a dual-VM design.
    • Runs on Windows, Linux, macOS, Qubes, KVM, USB, ISO and Raspberry Pi.
    • Says all its source code uses OSI approved licenses.

    访问 Whonix 检查日期 2026-10-19
