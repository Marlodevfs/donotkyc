VPN 与 Tor 泄漏测试

连接 VPN 或 Tor 后，打开其中一个页面。它会显示网络看到的 IP 地址和 DNS 服务器。

其中几个网站属于 VPN 公司。

排序：工具向你要什么（什么都不要、账户、证件），然后开源在闭源之前，最后按字母顺序。推广链接和赞助商不会改变排序。

  1. AmIUnique

    要求: 无 代码: 未说明
    • 检查你的浏览器指纹。
    • 研究项目，联系方式属于一所法国大学（里尔）。

    访问 AmIUnique 检查日期 2026-10-19

  2. Cover Your Tracks

    要求: 无 代码: 未说明
    • 显示追踪器如何看待你的浏览器，以及哪些特征会暴露你。
    • 由电子前哨基金会（EFF）运营。

    访问 Cover Your Tracks 检查日期 2026-10-19

  3. dnsleaktest.com

    要求: 无 代码: 未说明
    • DNS 泄漏测试，同时显示你的 IP 地址和大致位置。
    • 其页脚写着 IVPN Limited。

    访问 dnsleaktest.com 检查日期 2026-10-19

  4. ipleak.net

    要求: 无 代码: 未说明
    • 测试你的 IP 地址、DNS 解析器、WebRTC 和种子下载暴露情况。
    • 由 VPN 公司 AirVPN 运营。

    访问 ipleak.net 检查日期 2026-10-19

  5. Mullvad Check

    要求: 无 代码: 未说明
    • 测试 DNS 和 WebRTC 泄漏。需要 JavaScript。
    • 由 VPN 公司 Mullvad 运营。

    访问 Mullvad Check 检查日期 2026-10-19
