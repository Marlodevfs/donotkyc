门罗币钱包

电脑和手机上的门罗币（XMR）钱包。

代码在 GitHub 上时，条目会显示最新版本。

排序：工具向你要什么（什么都不要、账户、证件），然后开源在闭源之前，最后按字母顺序。推广链接和赞助商不会改变排序。

条目为英文。

  1. Aeonujo

    要求: 无 代码: 开源
    • Android wallet for Aeon, published by the Monerujo organisation on GitHub.
    • Described as "monerujoAE: An Android AEON Wallet". Apache 2 license.
    • No dedicated website. Last code change: May 2021.

    访问 Aeonujo 检查日期 2026-10-19

  2. Cake Wallet

    要求: 无 代码: 开源
    • Non-custodial wallet that also holds Monero. iOS, Android and Linux.
    • MIT license.

    访问 Cake Wallet 最新版本： 2026-10-12 检查日期 2026-10-19

  3. Feather Wallet

    要求: 无 代码: 开源
    • Free, open source Monero wallet for Linux, Tails, Windows and macOS.
    • Built to be easy for beginners, configurable for stricter threat models.
    • BSD-3 license.

    访问 Feather Wallet 最新版本： 2025-04-14 检查日期 2026-10-19

  4. Monero (official wallet)

    要求: 无 代码: 开源
    • The official Monero client, downloaded from getmonero.org.
    • The site links to the project's source code on GitHub.

    访问 Monero (official wallet) 最新版本： 2026-10-17 检查日期 2026-10-19

  5. Monerujo

    要求: 无 代码: 开源
    • Free, open source Monero wallet for Android.
    • Offers KYC-free swaps through Exolix.
    • Its footer reads "© 2024".

    访问 Monerujo 最新版本： 2025-06-17 检查日期 2026-10-19
