DoNotKYC 如何赚钱

DoNotKYC 免费阅读，没有付费墙。网站有两种收入来源，都不会改变任何条目。

推广链接

部分“访问”按钮是推广链接：如果你通过它注册，平台会把部分手续费分给我们。你不需要额外付费。目前有推广链接的平台：MEXC, Bybit, Nonkyc.io, KCEX。VPN 指南中的 NordVPN 和 Proton VPN 链接也是推广链接。

推广链接带有 rel="sponsored"。有推广链接的平台不会因此获得更好的身份等级、排名或描述。

赞助位与广告政策

企业可以付费在首页或专题页放置一个赞助位。每个赞助位都标明“赞助”，与排名列表分开，并使用 rel="sponsored" 链接。

  • 付费永远不会改变条目、其身份等级或排名。
  • 我们在接受前审核每个广告主，拒绝有可信诈骗或冻结资金举报的服务。
  • 如果出现损害用户的新证据，我们会撤下赞助位。
  • 我们不为广告主追踪访客：没有 Cookie，没有像素。
  • 当前赞助商列在广告页面。

我们不出售的东西

  • 排名、评测或“已验证”徽章。
  • 访客数据。我们不收集任何数据：见隐私政策。
  • 删除条目或警告。

谁决定排序

平台按照要求提供的身份信息多少排序，依据我们的方法说明。任何人都可以在 GitHub 上公开指出错误：报告变更。
