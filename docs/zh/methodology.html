我们如何核查平台

每个条目首先回答一个问题：这个平台要求多少身份信息，在什么时候要求？下面说明我们如何得出答案，以及每个条目核查到了什么程度。

DoNotKYC 是由 Marlodevfs 开发和维护的社区项目。代码和每次改动都在 GitHub 上公开。

三个身份等级

  • 无需：不要证件，也不要账户信息。你连接钱包或无需注册即可交易。
  • 轻度：在规定限额以下不要证件，或只要邮箱或手机号。
  • 分级：超过某个门槛需要证件。门槛写在条目中。

两种条目

文档整理：我们根据平台公布的条款、常见问题和帮助页面编写条目。所有条目都从这一步开始。

已测试：我们开了账户（或连接了钱包），通过平台转移了一笔小额真钱，并记录了被要求提供的每项信息。已测试条目会显示每次测试的日期和细节。 每个平台页面都会注明条目属于哪一种。测试正在逐个条目添加。

我们的真钱测试

  1. 在 VPN 下不做任何准备直接注册，记录每个被要求填写的字段。
  2. 用条目中描述的支付方式存入一小笔钱。
  3. 在主要交易对上交易或兑换一次。费用以收据为准，而不是营销页面。
  4. 提现到我们自己的钱包。大多数身份检查出现在这一步：我们记录限额和触发的时机。
  5. 带日期发布结果。测试超过 90 天的条目会重新排队。

条目变化时

如果平台对核心功能强制要求证件，我们会修改或移除条目。已关闭或被举报为骗局的平台会带着该状态继续保留，让搜索它的人看到警告。

我们先核实用户反馈再做任何改动。推荐平台或报告变更。

买不到的东西

收录、身份等级和目录中的位置都不能购买。部分“访问”链接是联盟链接，页面会注明。赞助位是单独的、标为广告的区块。
