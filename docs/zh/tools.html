隐私加密货币工具

钱包、VPN、Tor，以及在无 KYC 平台旁常用的其他工具。

每个条目转述厂商在自己网站上写的内容。赞助商从不在这些页面上买位置。

排序：工具向你要什么（什么都不要、账户、证件），然后开源在闭源之前，最后按字母顺序。推广链接和赞助商不会改变排序。

网络隐私

  • VPN 服务商VPN 向平台隐藏你的 IP 地址，向网络服务商隐藏你的流量。代价是你要信任 VPN 公司。9
  • Tor 与匿名网络这些网络让你的流量先经过其他计算机再到达目的地。速度比 VPN 慢。6
  • 加密 DNSDNS 把网站名称转换成地址。加密 DNS 让你的网络服务商读不到这些请求，读到它们的是你选的解析器。7
  • VPN 与 Tor 泄漏测试连接 VPN 或 Tor 后，打开其中一个页面。它会显示网络看到的 IP 地址和 DNS 服务器。5
  • 路由器与防火墙软件路由器软件可以为整个家庭网络设置 VPN 和 DNS 规则。2

隐私加密货币

  • 比特币钱包在自托管钱包里，密钥由你掌握，所以没有平台能要求你出示证件才能转移你的币。5
  • 硬件钱包硬件钱包把你的密钥保存在独立设备上。6
  • 门罗币钱包电脑和手机上的门罗币（XMR）钱包。5
  • CoinJoin 工具CoinJoin 是几个人共同构建的一笔比特币交易，用来提高各自付款的隐私。2
  • 隐私币旨在隐藏金额、发送方或接收方的币。3
  • 隐私支付在线付款时不向商家提供银行卡或手机号的方法。3

设备与账户

  • 电脑操作系统你的操作系统能看到你做的一切。这些系统从普通的 Linux 发行版到专为不留痕迹而设计的系统都有。12
  • 手机操作系统下面每个系统都会替换手机自带的 Android。请先看设备列表：每个系统只能在少数机型上运行。4
  • 隐私电子邮件服务商电子邮件服务商保存你的邮件，也知道你和谁通信。这些服务商说明自己如何加密、设在哪里，以及注册时要求什么。5
  • 邮件别名服务别名会把邮件转发到你真正的收件箱，所以网站永远看不到你的真实地址。别名一收到垃圾邮件，你就可以关掉它。2
