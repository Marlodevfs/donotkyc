安全建议

一份在无 KYC 平台上降低风险的检查清单。

密钥与备份

  • 优先自托管。助记词离线保存，绝不在陌生设备上输入。
  • 至少做两份金属或纸质备份，分别存放在不同地点。
  • 需要时使用 passphrase（BIP39）；存入资金前先演练恢复。

钓鱼与冒充

  • 手动输入交易所网址，或使用已核实的书签。
  • 合约和跨链桥地址只从官方渠道获取。
  • 绝不要把助记词、私钥或验证码交给 Telegram 或 Discord 上的“客服”。

恶意软件与漏洞

  • 为加密操作准备专用设备或浏览器配置文件。
  • 用只读钱包查看余额；尽量在隔离设备上签名。
  • 扫描文件，并校验所下载钱包的校验和。

交易卫生

  • 通过跨链桥或 DEX 转移大额前，先用小额测试。
  • 拆分大额转账；避免可预测的时间规律。
  • 加密保存交易记录（资产、交易哈希、交易对手）。

P2P 专项

  • 使用平台托管；最终结算前绝不放币。
  • 现金交易约在有监控的公共场所，必要时验钞。
  • 不要透露个人手机号；使用平台消息沟通。

安全是一个过程，而不是一件产品。请定期回顾这份清单，并根据新的威胁调整。
