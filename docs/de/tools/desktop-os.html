Betriebssysteme für Computer

Dein Betriebssystem sieht alles, was du tust. Diese reichen von gewöhnlichen Linux-Distributionen bis zu Systemen, die keine Spuren hinterlassen sollen.

Mehrere starten von einem USB-Stick oder in einer virtuellen Maschine, du kannst sie also testen, ohne deinen Rechner zu löschen.

Reihenfolge: was das Werkzeug von dir verlangt (nichts, ein Konto, einen Ausweis), dann offener vor geschlossenem Code, dann alphabetisch. Affiliate-Links und Sponsoren ändern sie nicht.

  1. Arch Linux

    Verlangt: nichts Code: Open Source
    • Unabhängig entwickelte GNU/Linux-Distribution für x86-64 mit Rolling Release.
    • Minimales Basissystem: Du fügst nur die Software hinzu, die du brauchst.

    Arch Linux besuchen Geprüft am 2026-10-19

  2. Debian

    Verlangt: nichts Code: Open Source
    • Nennt sich ein vollständig freies Betriebssystem, gebaut von einer Gemeinschaft von Menschen.

    Debian besuchen Geprüft am 2026-10-19

  3. Fedora Workstation

    Verlangt: nichts Code: Open Source
    • GNOME-Desktop auf Basis von Open-Source-Technik.
    • Gibt an, kostenlos und werbefrei zu sein und dass deine Daten dir gehören.

    Fedora Workstation besuchen Geprüft am 2026-10-19

  4. FreeBSD

    Verlangt: nichts Code: Open Source
    • Betriebssystem, bekannt für Netzwerkleistung und Stabilität.
    • BSD-artige Lizenz, die Weitergabe und Änderung erlaubt.

    FreeBSD besuchen Geprüft am 2026-10-19

  5. Kicksecure

    Verlangt: nichts Code: Open Source
    • Standardmäßig sicheres System auf Debian-Basis.
    • Läuft auf einem physischen Computer, von einem USB-Stick oder in einer virtuellen Maschine.
    • Gibt an, dass der gesamte Quellcode unter OSI-zugelassenen Lizenzen steht.

    Kicksecure besuchen Geprüft am 2026-10-19

  6. NixOS

    Verlangt: nichts Code: Open Source
    • Linux-System, das deklarativ mit Nix konfiguriert wird.
    • Gibt an, dass ein Paket, das auf einem Rechner läuft, auch auf einem anderen läuft.
    • Nix steht unter LGPL 2.1 und Nixpkgs unter MIT.

    NixOS besuchen Geprüft am 2026-10-19

  7. OpenBSD

    Verlangt: nichts Code: Open Source
    • Freies, plattformübergreifendes Unix-artiges Betriebssystem auf Basis von 4.4BSD.
    • Sagt: „Nur zwei Remote-Lücken in der Standardinstallation, seit sehr langer Zeit!“
    • Von Freiwilligen entwickelt und durch Spenden finanziert.

    OpenBSD besuchen Geprüft am 2026-10-19

  8. openSUSE Tumbleweed

    Verlangt: nichts Code: Open Source
    • Laufend aktualisiert: Man installiert es nur einmal.
    • Die Seite verlinkt auf den Quellcode und auf eine Lizenzseite.

    openSUSE Tumbleweed besuchen Geprüft am 2026-10-19

  9. Qubes OS

    Verlangt: nichts Code: Open Source
    • Freies Open-Source-System, aufgebaut auf Kompartimentierung.
    • Bringt die Sicherheit des Xen-Hypervisors auf Personal Computer.
    • Die Startseite verlinkt auf eine eigene Seite mit den Hardwareanforderungen.

    Qubes OS besuchen Geprüft am 2026-10-19

  10. secureblue

    Verlangt: nichts Code: Open Source
    • Sicherheitsorientiertes Desktop- und Server-Linux auf Basis von Fedora-Atomic-Desktop-Images.
    • Als Open-Source-Projekt entwickelt. Apache-2-Lizenz.

    secureblue besuchen Geprüft am 2026-10-19

  11. Tails

    Verlangt: nichts Code: Open Source
    • Startet von einem USB-Stick statt von Windows, macOS oder Linux.
    • Nutzt das Tor-Netzwerk für alles, was du online tust.
    • Gibt an, beim Herunterfahren keine Spuren auf dem Computer zu hinterlassen.
    • Freie Software, die unabhängige Forscher prüfen können.

    Tails besuchen Geprüft am 2026-10-19

  12. Whonix

    Verlangt: nichts Code: Open Source
    • Leitet den gesamten Internetverkehr über Tor, mit einer Zwei-VM-Architektur.
    • Läuft auf Windows, Linux, macOS, Qubes, KVM, USB, ISO und Raspberry Pi.
    • Gibt an, dass der gesamte Quellcode unter OSI-zugelassenen Lizenzen steht.

    Whonix besuchen Geprüft am 2026-10-19
