Tor und anonyme Netzwerke

Diese Netzwerke leiten deinen Datenverkehr über andere Rechner, bevor er sein Ziel erreicht. Sie sind langsamer als ein VPN.

Reihenfolge: was das Werkzeug von dir verlangt (nichts, ein Konto, einen Ausweis), dann offener vor geschlossenem Code, dann alphabetisch. Affiliate-Links und Sponsoren ändern sie nicht.

Die Einträge sind auf Englisch.

  1. Freenet

    Verlangt: nichts Code: Open Source
    • Peer-to-peer network for censorship-resistant publishing and communication, running since 1999.
    • The project calls itself Hyphanet, formerly Freenet.
    • Windows, Linux, macOS and other Unix systems.

    Freenet besuchen Letzte Version: 2026-09-04 Geprüft am 2026-10-19

  2. I2P

    Verlangt: nichts Code: Open Source
    • Decentralised network for private websites, messaging and file sharing.
    • Software is open source.

    I2P besuchen Letzte Version: 2026-07-24 Geprüft am 2026-10-19

  3. Onion Browser

    Verlangt: nichts Code: Open Source
    • Browser for iOS that connects through Tor. Free.
    • Made by Mike Tigas, Benjamin Erhart and the Guardian Project.

    Onion Browser besuchen Letzte Version: 2026-10-19 Geprüft am 2026-10-19

  4. Orbot

    Verlangt: nichts Code: Open Source
    • Sends traffic from any app on Android and iOS through Tor.
    • Android lets you pick which apps use Tor.
    • Supports bridges and onion services.

    Orbot besuchen Letzte Version: 2026-10-09 Geprüft am 2026-10-19

  5. Tor Browser

    Verlangt: nichts Code: Open Source
    • Free browser for desktop and Android.
    • The Tor Project also offers Tor VPN, in beta on Android.

    Tor Browser besuchen Geprüft am 2026-10-19

  6. Snowflake

    Verlangt: nichts Code: nicht angegeben
    • Connects you to Tor where Tor is blocked.
    • Routes through volunteer proxies in uncensored countries and looks like a video or voice call.

    Snowflake besuchen Geprüft am 2026-10-19
