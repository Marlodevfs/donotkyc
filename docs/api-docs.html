API Documentation

Simple, public, read‑only JSON served over HTTPS. No API key. Use it for prototypes, research and discovery tools.

Base URL

https://www.donotkyc.com/nokyc_directory.json

Versioned endpoint

https://www.donotkyc.com/api/v1/platforms.json

One flat list with every platform and all its fields (slug, kyc_level, blocked, status, tests, page and more). The shape stays stable inside v1. Affiliate links are not included.

Schema

Top-level keys:

centralized_exchanges decentralized_exchanges bridges atms p2p_marketplaces instant_swaps

Common fields

  • name (string)
  • type (enum: CEX, DEX, Bridge, ATM, P2P, Instant Swap)
  • url (string, website URL)
  • kyc_tier (string)
  • supported_countries (string; may later become array)
  • fiat_deposit (boolean)
  • fees (string)
  • cryptocurrencies (string)
  • features (array of strings)

cryptocurrencies can be null when unknown.

Example response

{
  "centralized_exchanges": [{ "name": "MEXC", "type": "CEX", "url": "https://www.mexc.com", "kyc_tier": "Tiered (up to 10 BTC/day no KYC)", "supported_countries": "Global except US", "fiat_deposit": false, "fees": "0.025% - 0.2%", "cryptocurrencies": "1600+", "features": ["Spot","Futures","Margin Trading"] }],
  "decentralized_exchanges": [{ "name": "Uniswap", "type": "DEX", "url": "https://app.uniswap.org", "kyc_tier": "None", "supported_countries": "Global", "fiat_deposit": false, "fees": "0.05% - 1%", "cryptocurrencies": "900+", "features": ["AMM","Liquidity pools","Governance"] }]
}

Usage

Client-side fetch

const DATA_URL = 'https://www.donotkyc.com/nokyc_directory.json';
fetch(DATA_URL)
  .then(r => r.json())
  .then(data => render(data))
  .catch(console.error);

CORS

GitHub Pages serves static JSON with CORS allow‑all by default for GET requests. Keep requests read‑only (no writes).

Rate limits

No strict limits, but please cache for 5 to 15 minutes and avoid aggressive polling.
