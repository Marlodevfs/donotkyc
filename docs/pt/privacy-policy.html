Política de privacidade

O DoNotKYC não vende dados e não guarda nenhum dado pessoal sobre você.

O que o site não usa

  • Nada de rastreadores de anúncios nem cookies.
  • Fontes, imagens e código vêm de www.donotkyc.com. O único script externo é o contador de visitas descrito abaixo.
  • Nada do que você digita neste site é enviado para nós. Envios e correções passam pelo GitHub, sob a política de privacidade do GitHub.

O que fica no seu dispositivo

Se você alternar entre tema claro e escuro, o navegador guarda a escolha no armazenamento local. A busca do site também roda no seu navegador: suas pesquisas não vão a lugar nenhum.

Contador de visitas

Contamos as visitas com o GoatCounter, um contador de código aberto sem cookies. Ele registra a página aberta, o site de origem, o navegador, o país e o tamanho da tela, nunca seu nome nem algo que te siga de um site a outro. Usamos para saber quantas pessoas leem o site.

Hospedagem

O site é hospedado no GitHub Pages. O GitHub registra o endereço IP dos visitantes por segurança. Não temos acesso a esses registros. Explicação do GitHub (em inglês).

Links para outros sites

Ao seguir o link de uma plataforma, você sai do DoNotKYC e vale a política daquele site. Um link de afiliado avisa a plataforma que você veio de nós; ele não nos diz nada sobre você. Veja como ganhamos dinheiro.

Alterações

As alterações desta política aparecem no changelog. Última atualização: 18 de outubro de 2026.
