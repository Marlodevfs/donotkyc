DNS criptografado

O DNS transforma o nome de um site em endereço. O DNS criptografado impede seu provedor de internet de ler esses pedidos. Quem os lê é o resolvedor que você escolher.

Ordem: o que a ferramenta pede de você (nada, uma conta, um documento de identidade), depois código aberto antes de fechado, depois ordem alfabética. Links de afiliado e patrocinadores não a mudam.

As fichas estão em inglês.

    Pede: nada Código: código aberto
    • Flexible DNS proxy for DNSCrypt v2, DNS over HTTPS, Anonymized DNSCrypt and Oblivious DoH.
    • Pre-built binaries for Android, BSD, Linux, macOS and Windows.
    • ISC license.

    Pede: nada Código: código aberto
    • DNS resolver and firewall app for Android.

    • Supports DNS over HTTPS and TLS and more than 190 blocklists.
