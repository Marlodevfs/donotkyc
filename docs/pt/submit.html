Anunciar

Sugerir uma plataforma

Conhece uma plataforma cripto onde se negocia sem enviar documento? Conte para nós. Entrar no diretório é grátis, ninguém pode comprar isso, e anunciantes não passam na frente.

Abrir o formulário

O que verificamos antes de listar

  • Os termos, a FAQ ou as páginas de ajuda da plataforma informam sua política KYC e seus limites. Um link para essa fonte é obrigatório.
  • O site funciona e a política bate com o que os usuários relatam.
  • Nenhum relato confiável de fuga com os fundos, fundos congelados sem motivo ou volume falso.
  • O nível de identidade (Nenhuma, Leve ou Por níveis) se encaixa na plataforma sem suposições.

Uma ficha está errada ou desatualizada

Se uma plataforma listada agora pede documento, mudou limites ou taxas, bloqueia novos países ou fechou, informe a mudança. Conferimos cada aviso antes de alterar uma ficha.

Privacidade

Os dois formulários são issues públicas do GitHub e exigem uma conta no GitHub. Não inclua dados pessoais e esconda nomes e números de conta nas capturas. Se a conta no GitHub for um problema, escreva para nós no Telegram.

Prefere anunciar?

Espaços patrocinados ficam separados das fichas e levam etiqueta. Veja como funciona a publicidade.
