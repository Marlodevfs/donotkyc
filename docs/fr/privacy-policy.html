Politique de confidentialité

DoNotKYC ne vend aucune donnée et ne conserve aucune donnée personnelle vous concernant.

Ce que le site n'utilise pas

  • Ni traceurs publicitaires, ni cookies.
  • Polices, images et code viennent de www.donotkyc.com. Le seul script extérieur est le compteur de visites décrit plus bas.
  • Rien de ce que vous tapez sur ce site ne nous est envoyé. Les propositions et corrections passent par GitHub, sous la politique de confidentialité de GitHub.

Ce qui reste sur votre appareil

Si vous passez du thème clair au thème sombre, votre navigateur retient ce choix en stockage local. La recherche du site tourne aussi dans votre navigateur : vos requêtes ne partent nulle part.

Compteur de visites

Nous comptons les visites avec GoatCounter, un compteur open source sans cookies. Il enregistre la page ouverte, le site d'origine, le navigateur, le pays et la taille d'écran, jamais votre nom ni rien qui vous suive d'un site à l'autre. Il nous sert à savoir combien de personnes lisent le site.

Hébergement

Le site est hébergé sur GitHub Pages. GitHub enregistre l'adresse IP des visiteurs pour des raisons de sécurité. Nous n'avons pas accès à ces journaux. Explication de GitHub (en anglais).

Liens vers d'autres sites

Quand vous suivez le lien d'une plateforme, vous quittez DoNotKYC et la politique de ce site s'applique. Un lien d'affiliation indique à la plateforme que vous venez de chez nous ; il ne nous apprend rien sur vous. Voir comment nous gagnons de l'argent.

Modifications

Les modifications de cette politique apparaissent dans le changelog. Dernière mise à jour : 18 octobre 2026.
