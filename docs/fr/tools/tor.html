Tor et réseaux anonymes

Ces réseaux font passer votre trafic par d'autres ordinateurs avant sa destination. Ils sont plus lents qu'un VPN.

Ordre : ce que l'outil vous demande (rien, un compte, une pièce d'identité), puis code ouvert avant code fermé, puis ordre alphabétique. Les liens d'affiliation et les sponsors ne le changent pas.

Les fiches sont en anglais.

  1. Freenet

    Demande: rien Code: open source
    • Peer-to-peer network for censorship-resistant publishing and communication, running since 1999.
    • The project calls itself Hyphanet, formerly Freenet.
    • Windows, Linux, macOS and other Unix systems.

    Visiter Freenet Dernière version : 2026-09-04 Vérifié le 2026-10-19

  2. I2P

    Demande: rien Code: open source
    • Decentralised network for private websites, messaging and file sharing.
    • Software is open source.

    Visiter I2P Dernière version : 2026-07-24 Vérifié le 2026-10-19

  3. Onion Browser

    Demande: rien Code: open source
    • Browser for iOS that connects through Tor. Free.
    • Made by Mike Tigas, Benjamin Erhart and the Guardian Project.

    Visiter Onion Browser Dernière version : 2026-10-19 Vérifié le 2026-10-19

  4. Orbot

    Demande: rien Code: open source
    • Sends traffic from any app on Android and iOS through Tor.
    • Android lets you pick which apps use Tor.
    • Supports bridges and onion services.

    Visiter Orbot Dernière version : 2026-10-09 Vérifié le 2026-10-19

  5. Tor Browser

    Demande: rien Code: open source
    • Free browser for desktop and Android.
    • The Tor Project also offers Tor VPN, in beta on Android.

    Visiter Tor Browser Vérifié le 2026-10-19

  6. Snowflake

    Demande: rien Code: non indiqué
    • Connects you to Tor where Tor is blocked.
    • Routes through volunteer proxies in uncensored countries and looks like a video or voice call.

    Visiter Snowflake Vérifié le 2026-10-19
