DNS chiffré

Le DNS transforme un nom de site en adresse. Un DNS chiffré empêche votre fournisseur d'accès de lire ces requêtes. C'est le résolveur que vous choisissez qui les lit.

Ordre : ce que l'outil vous demande (rien, un compte, une pièce d'identité), puis code ouvert avant code fermé, puis ordre alphabétique. Les liens d'affiliation et les sponsors ne le changent pas.

Les fiches sont en anglais.

  1. DNSCrypt-Proxy

    Demande: rien Code: open source
    • Flexible DNS proxy for DNSCrypt v2, DNS over HTTPS, Anonymized DNSCrypt and Oblivious DoH.
    • Pre-built binaries for Android, BSD, Linux, macOS and Windows.
    • ISC license.

    Visiter DNSCrypt-Proxy Vérifié le 2026-10-19

  2. Pi-hole

    Demande: rien Code: open source
    • Network-wide ad blocking.

    Visiter Pi-hole Dernière version : 2026-10-17 Vérifié le 2026-10-19

  3. RethinkDNS

    Demande: rien Code: open source
    • DNS resolver and firewall app for Android.
    • The app is free. The cloud DNS has a free and a paid tier.
    • Supports DNS over HTTPS and TLS and more than 190 blocklists.

    Visiter RethinkDNS Vérifié le 2026-10-19

  4. Unbound

    Demande: rien Code: open source
    • Validating, recursive, caching DNS resolver.

    Visiter Unbound Dernière version : 2026-09-16 Vérifié le 2026-10-19

  5. Quad9

    Demande: rien Code: non indiqué
    • Free. No sign-up, no account.
    • Says no data containing your IP address is ever logged in any Quad9 system.
    • Run by a not-for-profit foundation based in Zurich.
    • Blocks known malicious domains.

    Visiter Quad9 Vérifié le 2026-10-19

  6. Control D

    Demande: un compte Code: non indiqué
    • Supports DNS over HTTPS/3, TLS and QUIC.
    • Keeps query logs for 30 days on every plan.
    • Free trial without a card, then priced per device.
    • Its site does not state the company's jurisdiction.

    Visiter Control D Vérifié le 2026-10-19

  7. NextDNS

    Demande: un compte Code: non indiqué
    • Blocks threats, ads and trackers. Supports DNS over HTTPS and TLS.
    • You set log retention from one hour to two years, or turn logs off.
    • You pick where logs are stored: United States, European Union, United Kingdom or Switzerland.
    • You can start without signing up, but need an account to save settings.

    Visiter NextDNS Vérifié le 2026-10-19
