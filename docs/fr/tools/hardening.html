Renforcer sa vie privée

Renforcer sa vie privée, c'est boucher les failles des outils que vous utilisez déjà : navigateur, mots de passe, messages et fichiers.

Commencez par ce que vous utilisez tous les jours. Chaque fiche indique si son code est ouvert et ce qu'elle vous demande.

Ordre : ce que l'outil vous demande (rien, un compte, une pièce d'identité), puis code ouvert avant code fermé, puis ordre alphabétique. Les liens d'affiliation et les sponsors ne le changent pas.

Navigateurs

  1. LibreWolf

    Demande: rien Code: open source
    • Version personnalisée de Firefox axée sur la confidentialité, la sécurité et la liberté.
    • Vise à supprimer la télémétrie et la collecte de données. uBlock Origin est inclus.
    • Windows, Linux, macOS et OpenBSD.

    Visiter LibreWolf Vérifié le 2026-10-19

  2. Mullvad Browser

    Demande: rien Code: open source
    • Conçu avec le Tor Project pour limiter le suivi et les empreintes.
    • Vise à donner à tous les utilisateurs des empreintes similaires et utilise le letterboxing.
    • Linux, macOS et Windows. Gratuit, que vous utilisiez ou non Mullvad VPN.

    Visiter Mullvad Browser Dernière version : 2026-10-14 Vérifié le 2026-10-19

  3. Firefox

    Demande: rien Code: non indiqué
    • Créé par Mozilla, qui dit n'appartenir à aucun actionnaire.
    • Bloque automatiquement les traceurs. Dit qu'il ne vendra jamais vos données personnelles.
    • Windows, macOS, Linux, iOS et Android.
    • Sa page ne fait aucune déclaration sur l'open source.

    Visiter Firefox Vérifié le 2026-10-19

Extensions

  1. uBlock Origin

    Demande: rien Code: open source
    • Bloqueur de contenu pour Chromium et Firefox, conçu pour peu solliciter le processeur et la mémoire.
    • Fonctionne mieux sur Firefox, sur ordinateur et Android. Sa fiche sur le Chrome Web Store a été retirée.
    • Licence GPLv3.

    Visiter uBlock Origin Dernière version : 2026-09-16 Vérifié le 2026-10-19

Moteurs de recherche

  1. SearXNG

    Demande: rien Code: open source
    • Métamoteur de recherche gratuit qui rassemble les résultats de jusqu'à 264 services de recherche.
    • Dit que les utilisateurs ne sont ni suivis ni profilés. Vous pouvez héberger votre propre instance ou l'utiliser via Tor.
    • Licence AGPL-3.0.

    Visiter SearXNG Vérifié le 2026-10-19

  2. DuckDuckGo

    Demande: rien Code: non indiqué
    • Dit : « DuckDuckGo ne vous suit jamais. »
    • Dit que ses publicités sont diffusées en partenariat avec Microsoft et que leur affichage est anonyme.
    • La page que nous avons lue ne dit pas d'où viennent ses résultats de recherche.

    Visiter DuckDuckGo Vérifié le 2026-10-19

  3. Mojeek

    Demande: rien Code: non indiqué
    • Moteur de recherche avec son propre index de plus de neuf milliards de pages.
    • Dit proposer une recherche indépendante sans suivi depuis plus de 15 ans.

    Visiter Mojeek Vérifié le 2026-10-19

Gestionnaires de mots de passe

  1. KeePassDX

    Demande: rien Code: open source
    • Gestionnaire de mots de passe pour Android qui ouvre les bases de données KeePass.
    • Licence GPL-3.0.

    Visiter KeePassDX Dernière version : 2026-10-17 Vérifié le 2026-10-19

  2. KeePassXC

    Demande: rien Code: open source
    • Gestionnaire de mots de passe open source qui garde vos mots de passe dans un fichier chiffré hors ligne.
    • Dit qu'aucune donnée n'est stockée sur des serveurs distants.
    • Windows, macOS et Linux. Licence GPLv3.

    Visiter KeePassXC Dernière version : 2026-03-10 Vérifié le 2026-10-19

  3. Bitwarden

    Demande: un compte Code: open source
    • Gestionnaire de mots de passe open source et chiffré de bout en bout.
    • Toujours gratuit pour la gestion de base des mots de passe.
    • Dit publier les résultats de ses audits de sécurité réalisés par des tiers.
    • Les offres pour entreprises peuvent être auto-hébergées.

    Visiter Bitwarden Dernière version : 2026-10-15 Vérifié le 2026-10-19

  4. Proton Pass

    Demande: un compte Code: open source
    • Gestionnaire de mots de passe chiffré de bout en bout avec une offre gratuite : identifiants, notes et cartes en nombre illimité.
    • L'offre gratuite comprend 10 alias hide-my-email.
    • Son tableau comparatif présente Proton Pass comme open source.

    Visiter Proton Pass Vérifié le 2026-10-19

Double authentification et clés de sécurité

  1. Aegis Authenticator

    Demande: rien Code: open source
    • Application d'authentification gratuite et open source pour Android.

    Visiter Aegis Authenticator Dernière version : 2026-09-06 Vérifié le 2026-10-19

  2. Nitrokey

    Demande: rien Code: open source
    • Entreprise allemande qui vend du matériel de sécurité open source, dont des clés de sécurité.
    • Dit que ses produits sont fabriqués en Allemagne.

    Visiter Nitrokey Dernière version : 2026-09-30 Vérifié le 2026-10-19

  3. YubiKey

    Demande: rien Code: non indiqué
    • Gamme de clés de sécurité compatibles avec FIDO2, U2F, carte à puce, OTP et OpenPGP.
    • Sa page ne dit pas où elle est fabriquée et ne fait aucune déclaration sur l'open source.

    Visiter YubiKey Vérifié le 2026-10-19

  4. Ente Auth

    Demande: non indiqué Code: open source
    • Application d'authentification 2FA open source avec sauvegardes cloud chiffrées de bout en bout.
    • Applications pour mobile, ordinateur et web. Gratuit.

    Visiter Ente Auth Vérifié le 2026-10-19

Messageries

  1. SimpleX Chat

    Demande: rien Code: open source
    • Messagerie sans identifiant d'utilisateur, pas même aléatoire.
    • Dit qu'aucune entité ne contrôle le réseau et que tout le monde peut faire tourner des serveurs.
    • Ordinateur, iOS et Android.

    Visiter SimpleX Chat Dernière version : 2026-09-26 Vérifié le 2026-10-19

  2. Briar

    Demande: non indiqué Code: open source
    • Messagerie pair à pair qui contourne les serveurs centraux, par Bluetooth, Wi-Fi ou Tor.
    • Libre et open source. Distribuée sur Google Play et F-Droid.
    • Sa page ne dit pas si un compte est exigé.

    Visiter Briar Vérifié le 2026-10-19

  3. Molly

    Demande: non indiqué Code: open source
    • Fork indépendant de Signal pour Android, avec une base de données chiffrée par mot de passe et la prise en charge de Tor via Orbot.
    • Dit être entièrement libre, sans blobs propriétaires.

    Visiter Molly Dernière version : 2026-07-31 Vérifié le 2026-10-19

  4. Signal

    Demande: non indiqué Code: open source
    • Messagerie gérée par une association indépendante à but non lucratif, avec chiffrement de bout en bout.
    • Fondée sur le protocole Signal, open source.
    • Sa page ne dit pas si un numéro de téléphone est exigé.

    Visiter Signal Dernière version : 2026-10-13 Vérifié le 2026-10-19

Chiffrement

  1. Cryptomator

    Demande: rien Code: open source
    • Chiffrement côté client pour les fichiers que vous gardez dans n'importe quel cloud.
    • Open source. Le téléchargement pour ordinateur est gratuit.

    Visiter Cryptomator Dernière version : 2026-06-29 Vérifié le 2026-10-19

  2. GnuPG

    Demande: rien Code: open source
    • Implémentation libre du standard OpenPGP, utilisée en ligne de commande.
    • Logiciel libre depuis 1997, sous licence GNU GPL.
    • Une version Windows est disponible via Gpg4win.

    Visiter GnuPG Vérifié le 2026-10-19

  3. VeraCrypt

    Demande: rien Code: open source
    • Logiciel libre et open source de chiffrement de disque pour Windows, macOS et Linux, basé sur TrueCrypt 7.1a.
    • Les notes de sa version 1.19 mentionnent des correctifs issus d'un audit de Quarkslab financé par l'OSTIF.

    Visiter VeraCrypt Dernière version : 2026-06-12 Vérifié le 2026-10-19

Nettoyeurs de métadonnées

  1. BleachBit

    Demande: rien Code: open source
    • Nettoyeur open source de fichiers temporaires, caches de navigateur, journaux et traces.
    • Suppression sécurisée de fichiers. Windows et Linux.
    • Licence GPLv3.

    Visiter BleachBit Dernière version : 2026-09-08 Vérifié le 2026-10-19

  2. ExifTool

    Demande: rien Code: non indiqué
    • Lit, écrit et modifie les métadonnées d'une grande variété de fichiers.
    • Supprime les métadonnées une à une, par groupes ou en totalité. Sa page dit que la suppression n'est pas garantie complète.

    Visiter ExifTool Vérifié le 2026-10-19

  3. MAT2

    Demande: rien Code: non indiqué
    • Outil de suppression de métadonnées pour de nombreux formats de fichiers courants, écrit en Python 3.
    • Une bibliothèque avec une interface en ligne de commande et des extensions pour gestionnaires de fichiers.

    Visiter MAT2 Vérifié le 2026-10-19

Partage de fichiers

  1. OnionShare

    Demande: rien Code: open source
    • Outil open source qui partage des fichiers via Tor. Il peut aussi héberger un site onion ou un chat.
    • Windows, macOS, Linux, Android et iOS. Licence GPLv3.

    Visiter OnionShare Dernière version : 2026-10-16 Vérifié le 2026-10-19

  2. Syncthing

    Demande: rien Code: open source
    • Synchronisation continue de fichiers entre vos propres ordinateurs, sans serveur central.
    • Windows, macOS, Linux, FreeBSD et plus. Licence MPL-2.0, d'après son dépôt.

    Visiter Syncthing Dernière version : 2026-10-06 Vérifié le 2026-10-19
