Rafforzare la privacy

Rafforzare la privacy significa chiudere le falle negli strumenti che già usi: browser, password, messaggi e file.

Parti da ciò che usi ogni giorno. Ogni scheda indica se il codice è aperto e cosa ti chiede.

Ordine: ciò che lo strumento ti chiede (niente, un account, un documento), poi codice aperto prima di quello chiuso, poi ordine alfabetico. I link di affiliazione e gli sponsor non lo cambiano.

Browser

  1. LibreWolf

    Chiede: niente Codice: open source
    • Versione personalizzata di Firefox orientata a privacy, sicurezza e libertà.
    • Punta a rimuovere telemetria e raccolta dati. uBlock Origin è incluso.
    • Windows, Linux, macOS e OpenBSD.

    Visita LibreWolf Verificato il 2026-10-19

  2. Mullvad Browser

    Chiede: niente Codice: open source
    • Costruito con il Tor Project per ridurre tracciamento e impronte.
    • Punta a dare a tutti gli utenti impronte simili e usa il letterboxing.
    • Linux, macOS e Windows. Gratis, che tu usi o no Mullvad VPN.

    Visita Mullvad Browser Ultima versione: 2026-10-14 Verificato il 2026-10-19

  3. Firefox

    Chiede: niente Codice: non indicato
    • Creato da Mozilla, che dice di non appartenere ad azionisti.
    • Blocca automaticamente i tracker. Dice che non venderà mai i tuoi dati personali.
    • Windows, macOS, Linux, iOS e Android.
    • La pagina non fa alcuna dichiarazione sull'open source.

    Visita Firefox Verificato il 2026-10-19

Estensioni

  1. uBlock Origin

    Chiede: niente Codice: open source
    • Blocco dei contenuti per Chromium e Firefox, pensato per usare poca CPU e memoria.
    • Funziona meglio su Firefox, su desktop e Android. La sua scheda sul Chrome Web Store è stata rimossa.
    • Licenza GPLv3.

    Visita uBlock Origin Ultima versione: 2026-09-16 Verificato il 2026-10-19

Motori di ricerca

  1. SearXNG

    Chiede: niente Codice: open source
    • Metamotore di ricerca gratuito che raccoglie risultati da fino a 264 servizi di ricerca.
    • Dice che gli utenti non sono né tracciati né profilati. Puoi ospitare una tua istanza o usarlo tramite Tor.
    • Licenza AGPL-3.0.

    Visita SearXNG Verificato il 2026-10-19

  2. DuckDuckGo

    Chiede: niente Codice: non indicato
    • Dice: «DuckDuckGo non ti traccia mai».
    • Dice che la sua pubblicità è in partnership con Microsoft e che vederla è anonimo.
    • La pagina che abbiamo letto non dice da dove vengono i suoi risultati.

    Visita DuckDuckGo Verificato il 2026-10-19

  3. Mojeek

    Chiede: niente Codice: non indicato
    • Motore di ricerca con un proprio indice di oltre nove miliardi di pagine.
    • Dice di offrire ricerca indipendente senza tracciamento da oltre 15 anni.

    Visita Mojeek Verificato il 2026-10-19

Gestori di password

  1. KeePassDX

    Chiede: niente Codice: open source
    • Gestore di password per Android che apre i database KeePass.
    • Licenza GPL-3.0.

    Visita KeePassDX Ultima versione: 2026-10-17 Verificato il 2026-10-19

  2. KeePassXC

    Chiede: niente Codice: open source
    • Gestore di password open source che conserva le password in un file cifrato offline.
    • Dice che nessun dato è archiviato su server remoti.
    • Windows, macOS e Linux. Licenza GPLv3.

    Visita KeePassXC Ultima versione: 2026-03-10 Verificato il 2026-10-19

  3. Bitwarden

    Chiede: un account Codice: open source
    • Gestore di password open source con cifratura end-to-end.
    • Sempre gratuito per la gestione di base delle password.
    • Dice di pubblicare i risultati dei suoi audit di sicurezza condotti da terzi.
    • I piani aziendali possono essere ospitati in proprio.

    Visita Bitwarden Ultima versione: 2026-10-15 Verificato il 2026-10-19

  4. Proton Pass

    Chiede: un account Codice: open source
    • Gestore di password con cifratura end-to-end e piano gratuito: accessi, note e carte illimitati.
    • Il piano gratuito include 10 alias hide-my-email.
    • La sua tabella comparativa indica Proton Pass come open source.

    Visita Proton Pass Verificato il 2026-10-19

Due fattori e chiavi di sicurezza

  1. Aegis Authenticator

    Chiede: niente Codice: open source
    • App di autenticazione gratuita e open source per Android.

    Visita Aegis Authenticator Ultima versione: 2026-09-06 Verificato il 2026-10-19

  2. Nitrokey

    Chiede: niente Codice: open source
    • Azienda tedesca che vende hardware di sicurezza open source, comprese chiavi di sicurezza.
    • Dice che i suoi prodotti sono fabbricati in Germania.

    Visita Nitrokey Ultima versione: 2026-09-30 Verificato il 2026-10-19

  3. YubiKey

    Chiede: niente Codice: non indicato
    • Serie di chiavi di sicurezza che supporta FIDO2, U2F, smart card, OTP e OpenPGP.
    • La pagina non dice dove viene prodotta e non fa dichiarazioni sull'open source.

    Visita YubiKey Verificato il 2026-10-19

  4. Ente Auth

    Chiede: non indicato Codice: open source
    • Autenticatore 2FA open source con backup cloud cifrati end-to-end.
    • App per mobile, desktop e web. Gratis.

    Visita Ente Auth Verificato il 2026-10-19

Messaggistica

  1. SimpleX Chat

    Chiede: niente Codice: open source
    • Messaggistica senza identificatori utente, nemmeno casuali.
    • Dice che nessuna entità controlla la rete e che chiunque può gestire server.
    • Desktop, iOS e Android.

    Visita SimpleX Chat Ultima versione: 2026-09-26 Verificato il 2026-10-19

  2. Briar

    Chiede: non indicato Codice: open source
    • Messaggistica peer-to-peer che evita i server centrali, via Bluetooth, Wi-Fi o Tor.
    • Libera e open source. Distribuita su Google Play e F-Droid.
    • La pagina non dice se è richiesto un account.

    Visita Briar Verificato il 2026-10-19

  3. Molly

    Chiede: non indicato Codice: open source
    • Fork indipendente di Signal per Android, con database protetto da passphrase e supporto a Tor tramite Orbot.
    • Dice di essere software completamente libero, senza blob proprietari.

    Visita Molly Ultima versione: 2026-07-31 Verificato il 2026-10-19

  4. Signal

    Chiede: non indicato Codice: open source
    • Messaggistica gestita da un'organizzazione indipendente senza scopo di lucro, con cifratura end-to-end.
    • Basata sul protocollo Signal, open source.
    • La pagina non dice se è richiesto un numero di telefono.

    Visita Signal Ultima versione: 2026-10-13 Verificato il 2026-10-19

Cifratura

  1. Cryptomator

    Chiede: niente Codice: open source
    • Cifratura lato client per i file che tieni in qualsiasi cloud.
    • Open source. Il download per desktop è gratuito.

    Visita Cryptomator Ultima versione: 2026-06-29 Verificato il 2026-10-19

  2. GnuPG

    Chiede: niente Codice: open source
    • Implementazione libera dello standard OpenPGP, usata da riga di comando.
    • Software libero dal 1997, con licenza GNU GPL.
    • È disponibile una versione per Windows tramite Gpg4win.

    Visita GnuPG Verificato il 2026-10-19

  3. VeraCrypt

    Chiede: niente Codice: open source
    • Software libero e open source di cifratura del disco per Windows, macOS e Linux, basato su TrueCrypt 7.1a.
    • Le note della versione 1.19 citano correzioni derivate da un audit di Quarkslab finanziato da OSTIF.

    Visita VeraCrypt Ultima versione: 2026-06-12 Verificato il 2026-10-19

Pulitori di metadati

  1. BleachBit

    Chiede: niente Codice: open source
    • Pulitore open source di file temporanei, cache del browser, log e tracce.
    • Eliminazione sicura dei file. Windows e Linux.
    • Licenza GPLv3.

    Visita BleachBit Ultima versione: 2026-09-08 Verificato il 2026-10-19

  2. ExifTool

    Chiede: niente Codice: non indicato
    • Legge, scrive e modifica i metadati in un'ampia varietà di file.
    • Elimina i metadati uno per uno, per gruppi o tutti insieme. La pagina dice che la rimozione completa non è garantita.

    Visita ExifTool Verificato il 2026-10-19

  3. MAT2

    Chiede: niente Codice: non indicato
    • Strumento di rimozione dei metadati per molti formati di file comuni, scritto in Python 3.
    • Una libreria con interfaccia a riga di comando ed estensioni per i gestori di file.

    Visita MAT2 Verificato il 2026-10-19

Condivisione di file

  1. OnionShare

    Chiede: niente Codice: open source
    • Strumento open source che condivide file tramite Tor. Può anche ospitare un sito onion o una chat.
    • Windows, macOS, Linux, Android e iOS. Licenza GPLv3.

    Visita OnionShare Ultima versione: 2026-10-16 Verificato il 2026-10-19

  2. Syncthing

    Chiede: niente Codice: open source
    • Sincronizzazione continua dei file tra i tuoi computer, senza server centrale.
    • Windows, macOS, Linux, FreeBSD e altri. Licenza MPL-2.0, secondo il repository.

    Visita Syncthing Ultima versione: 2026-10-06 Verificato il 2026-10-19
