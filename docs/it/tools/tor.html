Tor e reti anonime

Queste reti fanno passare il tuo traffico da altri computer prima della destinazione. Sono più lente di una VPN.

Ordine: ciò che lo strumento ti chiede (niente, un account, un documento), poi codice aperto prima di quello chiuso, poi ordine alfabetico. I link di affiliazione e gli sponsor non lo cambiano.

Le schede sono in inglese.

  1. Freenet

    Chiede: niente Codice: open source
    • Peer-to-peer network for censorship-resistant publishing and communication, running since 1999.
    • The project calls itself Hyphanet, formerly Freenet.
    • Windows, Linux, macOS and other Unix systems.

    Visita Freenet Ultima versione: 2026-09-04 Verificato il 2026-10-19

  2. I2P

    Chiede: niente Codice: open source
    • Decentralised network for private websites, messaging and file sharing.
    • Software is open source.

    Visita I2P Ultima versione: 2026-07-24 Verificato il 2026-10-19

  3. Onion Browser

    Chiede: niente Codice: open source
    • Browser for iOS that connects through Tor. Free.
    • Made by Mike Tigas, Benjamin Erhart and the Guardian Project.

    Visita Onion Browser Ultima versione: 2026-10-19 Verificato il 2026-10-19

  4. Orbot

    Chiede: niente Codice: open source
    • Sends traffic from any app on Android and iOS through Tor.
    • Android lets you pick which apps use Tor.
    • Supports bridges and onion services.

    Visita Orbot Ultima versione: 2026-10-09 Verificato il 2026-10-19

  5. Tor Browser

    Chiede: niente Codice: open source
    • Free browser for desktop and Android.
    • The Tor Project also offers Tor VPN, in beta on Android.

    Visita Tor Browser Verificato il 2026-10-19

  6. Snowflake

    Chiede: niente Codice: non indicato
    • Connects you to Tor where Tor is blocked.
    • Routes through volunteer proxies in uncensored countries and looks like a video or voice call.

    Visita Snowflake Verificato il 2026-10-19
