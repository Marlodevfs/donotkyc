Wallet Monero

Wallet per Monero (XMR) su computer e telefono.

Ogni scheda mostra l'ultima versione quando il codice è su GitHub.

Ordine: ciò che lo strumento ti chiede (niente, un account, un documento), poi codice aperto prima di quello chiuso, poi ordine alfabetico. I link di affiliazione e gli sponsor non lo cambiano.

Le schede sono in inglese.

  1. Aeonujo

    Chiede: niente Codice: open source
    • Android wallet for Aeon, published by the Monerujo organisation on GitHub.
    • Described as "monerujoAE: An Android AEON Wallet". Apache 2 license.
    • No dedicated website. Last code change: May 2021.

    Visita Aeonujo Verificato il 2026-10-19

  2. Cake Wallet

    Chiede: niente Codice: open source
    • Non-custodial wallet that also holds Monero. iOS, Android and Linux.
    • MIT license.

    Visita Cake Wallet Ultima versione: 2026-10-12 Verificato il 2026-10-19

  3. Feather Wallet

    Chiede: niente Codice: open source
    • Free, open source Monero wallet for Linux, Tails, Windows and macOS.
    • Built to be easy for beginners, configurable for stricter threat models.
    • BSD-3 license.

    Visita Feather Wallet Ultima versione: 2025-04-14 Verificato il 2026-10-19

  4. Monero (official wallet)

    Chiede: niente Codice: open source
    • The official Monero client, downloaded from getmonero.org.
    • The site links to the project's source code on GitHub.

    Visita Monero (official wallet) Ultima versione: 2026-10-17 Verificato il 2026-10-19

  5. Monerujo

    Chiede: niente Codice: open source
    • Free, open source Monero wallet for Android.
    • Offers KYC-free swaps through Exolix.
    • Its footer reads "© 2024".

    Visita Monerujo Ultima versione: 2025-06-17 Verificato il 2026-10-19
