Hardware wallets

A hardware wallet keeps your keys on a separate device.

Each entry shows whether the maker says its code is open.

Order: what the tool asks of you (nothing, an account, ID), then open code before closed code, then A to Z. Affiliate links and sponsors never change it.

  1. BitBox

    Asks of you: nothing Code: open source
    • Swiss hardware wallet. The Bitcoin-only edition runs firmware that supports only Bitcoin.
    • Says the firmware is open source with reproducible builds and a bug bounty.
    • Our checker could not open this site, so these points come from the page as indexed by a search engine.

    Visit BitBox Latest release: 2026-08-31 Checked 2026-10-19

  2. KeepKey

    Asks of you: nothing Code: open source
    • Hardware wallet sold by KEEPKEY LLC, founded in 2014.
    • Says its firmware is open source and the hardware fully auditable.

    Visit KeepKey Latest release: 2026-10-16 Checked 2026-10-19

  3. Satochip

    Asks of you: nothing Code: open source
    • Hardware wallet in the form of an NFC smartcard with an EAL6+ certified secure element.
    • Says its software is open source.
    • Its page lists no price.

    Visit Satochip Checked 2026-10-19

  4. Trezor

    Asks of you: nothing Code: open source
    • Says its code and design are 100% open source. Sold since 2013.
    • Says private keys are generated in the device and held only by you.
    • Its page cites no independent audit.

    Visit Trezor Checked 2026-10-19

  5. Ledger

    Asks of you: nothing Code: closed
    • Non-custodial hardware wallets with a secure element chip.
    • Its site calls the Ledger operating system proprietary and makes no open source claim.

    Visit Ledger Checked 2026-10-19

  6. imKey

    Asks of you: nothing Code: not stated
    • Hardware wallet with an Infineon secure element certified CC EAL6+.
    • Its site does not name a manufacturer and does not mention open source.

    Visit imKey Checked 2026-10-19
