Bilgisayarlar için işletim sistemleri

İşletim sistemin yaptığın her şeyi görür. Bunlar sıradan Linux dağıtımlarından iz bırakmamak için yapılmış sistemlere kadar uzanır.

Birçoğu USB bellekten ya da sanal makinede açılır, böylece bilgisayarını silmeden deneyebilirsin.

Sıra: aracın senden ne istediği (hiçbir şey, bir hesap, kimlik), sonra açık kod kapalı koddan önce, sonra alfabetik. Ortaklık bağlantıları ve sponsorlar bunu değiştirmez.

  1. Arch Linux

    İstediği: hiçbir şey Kod: açık kaynak
    • Sürekli güncellenen, bağımsız geliştirilen x86-64 GNU/Linux dağıtımı.
    • Asgari temel sistem: yalnızca ihtiyacın olan yazılımı eklersin.

    Arch Linux sitesine git Kontrol tarihi 2026-10-19

  2. Debian

    İstediği: hiçbir şey Kod: açık kaynak
    • Kendini bir topluluk tarafından yapılan, tamamen özgür bir işletim sistemi olarak tanımlıyor.

    Debian sitesine git Kontrol tarihi 2026-10-19

  3. Fedora Workstation

    İstediği: hiçbir şey Kod: açık kaynak
    • Açık kaynak teknoloji üzerine kurulu GNOME masaüstü.
    • Ücretsiz olduğunu, reklam içermediğini ve verilerinin sana ait olduğunu söylüyor.

    Fedora Workstation sitesine git Kontrol tarihi 2026-10-19

  4. FreeBSD

    İstediği: hiçbir şey Kod: açık kaynak
    • Ağ performansı ve kararlılığıyla bilinen işletim sistemi.
    • Yeniden dağıtıma ve değiştirmeye izin veren BSD tarzı lisans.

    FreeBSD sitesine git Kontrol tarihi 2026-10-19

  5. Kicksecure

    İstediği: hiçbir şey Kod: açık kaynak
    • Debian tabanlı, varsayılan olarak güvenli sistem.
    • Fiziksel bilgisayarda, USB bellekten veya sanal makinede çalışır.
    • Tüm kaynak kodunun OSI onaylı lisanslar kullandığını söylüyor.

    Kicksecure sitesine git Kontrol tarihi 2026-10-19

  6. NixOS

    İstediği: hiçbir şey Kod: açık kaynak
    • Nix ile bildirimsel olarak yapılandırılan Linux sistemi.
    • Bir makinede çalışan paketin başka bir makinede de çalıştığını söylüyor.
    • Nix LGPL 2.1, Nixpkgs ise MIT lisanslı.

    NixOS sitesine git Kontrol tarihi 2026-10-19

  7. OpenBSD

    İstediği: hiçbir şey Kod: açık kaynak
    • 4.4BSD tabanlı, özgür, çok platformlu Unix benzeri işletim sistemi.
    • Şöyle diyor: “Varsayılan kurulumda çok uzun zamandır yalnızca iki uzaktan açık.”
    • Gönüllüler tarafından geliştiriliyor ve bağışlarla finanse ediliyor.

    OpenBSD sitesine git Kontrol tarihi 2026-10-19

  8. openSUSE Tumbleweed

    İstediği: hiçbir şey Kod: açık kaynak
    • Sürekli güncellenir: bir kez kurarsın.
    • Sayfası kaynak koduna ve bir lisans sayfasına bağlantı veriyor.

    openSUSE Tumbleweed sitesine git Kontrol tarihi 2026-10-19

  9. Qubes OS

    İstediği: hiçbir şey Kod: açık kaynak
    • Bölmelendirme üzerine kurulu özgür ve açık kaynak sistem.
    • Xen hipervizörünün güvenliğini kişisel bilgisayarlara getirir.
    • Ana sayfası donanım gereksinimleri için ayrı bir sayfaya bağlantı veriyor.

    Qubes OS sitesine git Kontrol tarihi 2026-10-19

  10. secureblue

    İstediği: hiçbir şey Kod: açık kaynak
    • Fedora Atomic Desktop imajları üzerine kurulu, güvenlik odaklı masaüstü ve sunucu Linux sistemi.
    • Açık kaynak proje olarak geliştiriliyor. Apache 2 lisansı.

    secureblue sitesine git Kontrol tarihi 2026-10-19

  11. Tails

    İstediği: hiçbir şey Kod: açık kaynak
    • Windows, macOS veya Linux yerine USB bellekten başlar.
    • Çevrimiçi yaptığın her şey için Tor ağını kullanır.
    • Kapatıldığında bilgisayarda iz bırakmadığını söylüyor.
    • Bağımsız araştırmacıların doğrulayabileceği özgür yazılım.

    Tails sitesine git Kontrol tarihi 2026-10-19

  12. Whonix

    İstediği: hiçbir şey Kod: açık kaynak
    • Tüm internet trafiğini iki sanal makineli bir tasarımla Tor'dan geçirir.
    • Windows, Linux, macOS, Qubes, KVM, USB, ISO ve Raspberry Pi üzerinde çalışır.
    • Tüm kaynak kodunun OSI onaylı lisanslar kullandığını söylüyor.

    Whonix sitesine git Kontrol tarihi 2026-10-19
