Şifreli DNS

DNS, bir site adını adrese çevirir. Şifreli DNS internet sağlayıcının bu istekleri okumasını engeller. Onları seçtiğin çözümleyici okur.

Sıra: aracın senden ne istediği (hiçbir şey, bir hesap, kimlik), sonra açık kod kapalı koddan önce, sonra alfabetik. Ortaklık bağlantıları ve sponsorlar bunu değiştirmez.

  1. DNSCrypt-Proxy

    İstediği: hiçbir şey Kod: açık kaynak
    • DNSCrypt v2, DNS over HTTPS, Anonymized DNSCrypt ve Oblivious DoH için esnek DNS vekili.
    • Android, BSD, Linux, macOS ve Windows için önceden derlenmiş ikili dosyalar.
    • ISC lisansı.

    DNSCrypt-Proxy sitesine git Kontrol tarihi 2026-10-19

  2. Pi-hole

    İstediği: hiçbir şey Kod: açık kaynak
    • Ağ genelinde reklam engelleme.

    Pi-hole sitesine git Son sürüm: 2026-10-17 Kontrol tarihi 2026-10-19

  3. RethinkDNS

    İstediği: hiçbir şey Kod: açık kaynak
    • Android için DNS çözümleyici ve güvenlik duvarı uygulaması.
    • Uygulama ücretsiz. Bulut DNS'in ücretsiz ve ücretli bir katmanı var.
    • DNS over HTTPS ve TLS ile 190'dan fazla engel listesini destekler.

    RethinkDNS sitesine git Kontrol tarihi 2026-10-19

  4. Unbound

    İstediği: hiçbir şey Kod: açık kaynak
    • Doğrulayan, özyinelemeli, önbellekli DNS çözümleyici.

    Unbound sitesine git Son sürüm: 2026-09-16 Kontrol tarihi 2026-10-19

  5. Quad9

    İstediği: hiçbir şey Kod: belirtilmemiş
    • Ücretsiz. Kayıt yok, hesap yok.
    • IP adresini içeren hiçbir verinin Quad9'un hiçbir sisteminde kaydedilmediğini söylüyor.
    • Zürih merkezli kâr amacı gütmeyen bir vakıf tarafından işletiliyor.
    • Bilinen zararlı alan adlarını engeller.

    Quad9 sitesine git Kontrol tarihi 2026-10-19

  6. Control D

    İstediği: bir hesap Kod: belirtilmemiş
    • DNS over HTTPS/3, TLS ve QUIC destekler.
    • Her planda sorgu kayıtlarını 30 gün tutar.
    • Kartsız ücretsiz deneme, sonra cihaz başına fiyat.
    • Sitesi şirketin hukuki yargı yetkisini belirtmiyor.

    Control D sitesine git Kontrol tarihi 2026-10-19

  7. NextDNS

    İstediği: bir hesap Kod: belirtilmemiş
    • Tehditleri, reklamları ve izleyicileri engeller. DNS over HTTPS ve TLS destekler.
    • Kayıt saklama süresini bir saatten iki yıla kadar ayarlarsın ya da kayıtları kapatırsın.
    • Kayıtların nerede saklanacağını seçersin: Amerika Birleşik Devletleri, Avrupa Birliği, Birleşik Krallık veya İsviçre.
    • Kayıt olmadan başlayabilirsin, ama ayarları kaydetmek için hesap gerekir.

    NextDNS sitesine git Kontrol tarihi 2026-10-19
